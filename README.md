# Circle Raider

Браузерный изометрический рогалик в стилистике тёмного фэнтези.

## Запуск

Откройте `index.html` в браузере. Игра собрана в одном файле и не требует установки зависимостей.

Также можно запустить `start-server.cmd` и открыть адрес, который появится в окне сервера.

## Управление

- `WASD` — движение.
- Мышь — направление взгляда и удара.
- Левая кнопка мыши — удар мечом.

## Что есть в игре

- шесть моделей меча с развитием от гладиуса до двуручного меча;
- точная зона удара по видимому размаху клинка;
- несколько типов противников, включая мечников, стрелков, копейщиков и босса с топором;
- волны, уровни, выбор усилений, опыт и таблица лидеров;
- разрушаемые кусты и бочки, лечебные зелья и неразрушаемые деревья;
- настройки масштаба игрового интерфейса.

Предыдущая главная страница проекта сохранена как `index.dread-blocks.backup.html`. Старые `game.js` и `styles.css` оставлены без изменений для совместимости с резервной страницей.
